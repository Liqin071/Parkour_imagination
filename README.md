# 创想大师 · 灵感世界修复计划（网页版跑酷 + 人格测评）

单文件 HTML 小游戏：剧情跑酷 + 5 次互动选择 + 无尽收集跑酷 + 七种创作人格档案。
无任何外部依赖（不含图片、字体、CDN），双击 `index.html` 即可玩。

## 操作

| 动作 | 电脑 | 手机 |
|---|---|---|
| 跳跃（**轻点=小跳，按住=大跳**） | 空格、↑、W（按下瞬间生效） | 右下「跳跃」按钮（点按/长按），或点画面任意空白处 |
| 二连跳 | 空中再按一次（同样分小跳/大跳） | 同 |
| 暂停 / 继续 | Esc | 左下「Ⅱ 暂停」 |
| 结束无尽模式并结算 | 右上「结束 · 结算」 | 同 |

## 流程

1. 剧情跑酷 5 段，**每段约 30 秒**；进入场景约 3 秒就会遇到第一批灵感，段末会出现一道**半透明竖向光墙（结界）**，撞上它就进入选择
2. 结界前 1 秒会有「灵感共鸣」预警特效，触碰瞬间弹出互动选择（共 5 题）；答题后有粒子退场 → 新场景浮现的过渡
3. 五次选择后进入**无尽模式**：速度逐渐加快，收集灵感碎片 / 麦克风 / 画笔，躲避「压力障碍」
4. 点右上「结束 · 结算」或生命耗尽 → 生成创作人格档案（可复制文案分享）

## 版本说明

当前版本相对早期版本的修复：

- 障碍物出现时的掉帧（逐帧 `shadowBlur`、被遮挡画布的重复重绘、每帧 DOM 写入）；障碍现在只是一次 `drawImage`
- 跳跃按下瞬间生效，并按**按住时长连续决定高度**（轻点≈93px，0.16s≈137px，0.30s≈176px），起跳后会留下光点尾迹
- 章节时长改为 30 秒，选择由**结界（半透明竖向光墙）**触发，前摇特效缩短并准时结束
- 灵感碎片弧线按真实跳跃轨迹生成（小跳弧线 / 大跳弧线分开）
- 特殊灵感（麦克风/画笔）出现频率提高并加了保底间隔，位置分轻点可拿与大跳可拿两种
- 进场空白由约 5.3s 缩短到约 3s
- 无尽模式**渐进加速**（255 → 收敛于 560）
- 场景切换加入粒子退场 + 淡入浮现的过渡特效
- 障碍与道具不再重叠生成，关卡改为分块生成、间距按速度计算
- 受击改为纯白闪反馈（不再顿帧、不震屏），受击判定重做为对称盒并对齐角色视觉
- 无尽模式新增「结束」按钮直接进入结算
